# Proyecto SQL – Análisis de Ventas

## Objetivo
Analizar un dataset de ventas respondiendo a preguntas de negocio
utilizando SQL.

## Preguntas respondidas
1. Número total de pedidos
2. Ventas totales
3. Beneficio total
4. Clientes distintos
5. Categoría con más ventas
6. Categoría con mayor beneficio
7. Ventas por año
8. Beneficio por mes
9. Top 10 clientes por ventas
10. Productos con pérdidas

## Herramientas
- MySQL
- MySQL Workbench

## Conclusiones
- Las ventas están concentradas en determinadas categorías
- Un grupo reducido de clientes genera gran parte de los ingresos
- No se detectan productos con pérdidas en el dataset analizado
